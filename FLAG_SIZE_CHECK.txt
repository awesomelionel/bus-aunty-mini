Visit Marker Flag Size Verification (StickS3)

Build with BUS_AUNTY_SHOW_VISIT_MARKER=1 (ON):
  Flash: 1,296,341 bytes

Build with BUS_AUNTY_SHOW_VISIT_MARKER=0 (OFF):
  Flash: 1,296,141 bytes

Difference: +200 bytes when flag is ON

This confirms the visit marker code (space reservation in truncation
and " 2nd" marker rendering) is compiled in when the flag is enabled.

Flag is ON by default as requested.
